# H3 多参内容整理

用于视频提示词优化的内容整理阶段。先阅读当前片段原稿、用户要求和工作台冻结的参考素材，整理出后续格式适配可直接使用的内容。保留用户已经写清的事实和次序。即使参考素材尚未齐全，也先整理有来源的内容，并按当前合同说明缺失的具体归属。

## 对齐参考素材与主体

1. 逐项核对本次素材的种类、标识与明确用途。沿用工作台给出的素材标识及顺序。对身份、外观、环境、构图、动作、实际首尾帧和声音分别记录已明确的归属。
2. 同一人物的多张参考归到同一已知主体。多人共用一张图时，只有在原稿或冻结来源明确区分身份的情况下才分配归属。让后续动作和对白沿用同一主体标识。参考图的出现顺序不能决定主体身份或帧位。
3. 把参考视频中用户指定沿用的动作、节奏或运镜对应到当前片段。保留参考音的原用途，分别处理指定人物的音色、指定沿用的音轨和其他声音参考。归属不明确时记录不确定性，勿凭音频顺序分配说话人。

## 整理动作与对白

1. 沿原稿梳理每段谁对谁做什么、动作与反应的先后、何时开口、何时切镜。保留用户给出的时长、时间点、景别、镜头切换和否定要求。只有原稿提供切换依据时才组织新镜头段。
2. 每句对白和旁白跟随原有的说话人和事件位置。逐字保留原语种的对白、歌词与可见画面文字，区分画内说话、画外音和无声内心活动。用户明确指定静音、无音乐或保留音轨时，照录声音意图。
3. 用户已明确某人使用某一路音色时，记录该人物、声音参考及对应发声事件的关系。没有绑定的说话人仍保留完整对白。音色参考不等于复用其音轨，指定音轨也不推导说话人的音色。

## 交付给格式适配

按宿主本次的结构返回事实、来源、引用及原文引句，使用已有的主体与素材标识。内容阶段保留可核对的对应关系，H3 的章节、标签、时间码写法和输出语言由所选格式方法处理。模型、输入模式和可用通道沿用工作台冻结的配置。发现矛盾或缺口时保留可确认的部分并具体指出，不补写人物、对白、素材、时序或设备能力。
