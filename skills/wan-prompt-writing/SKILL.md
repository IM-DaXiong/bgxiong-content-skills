# 万相视频提示词

## 片段与素材边界

片段从完整剧集或用户当前稿件出发，可以包含一个或多个连续剪辑镜头。镜头只表达片段内部的叙事次序，不要求先创建场次、故事板、静帧或逐镜业务记录。时长、镜头数和参考图数量以用户意图及本次冻结能力为准，不固定秒数，不要求先生成六张或九张图片。

图片是普通素材。人物外观、环境、风格、整片首尾或片内镜头边界等用途来自本次明确绑定；不能根据节点名、图片排列或画面猜测首尾。无参考图的合法输入也能完成内容表达。环境描述不要求一个旧场景实体，也不把环境图当成视频首帧。

本包只提供创作方法，只使用本次实际提供且已获授权的工具，不自行注册或调用其它能力。是否生成图片或视频由本次授权与实际可用工具决定，文字任务只交稿。

## 本次输入与格式适配

本用途负责把本次冻结的视频内容表达为目标格式，不重做剧情规划，也不要求审阅先通过。输入可由片段已保存稿件或内容整理产物提供；具体字段以调用方实际合同为准。若合同提供事实、内部镜头和引用 ID，只使用给定闭集；这不表示必须创建场次、故事板或镜头业务实体。

应用要求表达行时，通过本次给出的事实、引文与参考用途 ID 关联内容；引用 token、引文插入、镜头标题及机器时间码包装交给已绑定的目标适配器。应用只要求正文时直接交正文，不凭本文件发明表达行、冲突列表或新字段。没有匹配的引文槽位时完整保留原话，不能只留下“说话”的动作或静默删除。应用明确负责插入该次引文时不重复插入同一出现。

- 保留主体、动作、因果、时序、否定要求、声音与已有切镜；不为套模板新增灯光、道具、伤害、声音或镜头。
- 句子可按主体、动作、空间、环境、摄影和声音组织，顺序服务叙事，未提供的维度直接省略。
- 同一人物或物体用稳定称呼；参考用途保持实际绑定，不交换主体参考、环境、音色、音轨复用和首尾边界用途。
- 总时长、约数和事件时间完整保留。与工作台参数不一致时提示协调，不删除事件、不机械拆镜；是否真实可提交由当前目标能力及参数校验决定。
- 能力未知时说明未知，不从型号名推断不支持；实际声明不接受的模式或资源不能伪装成另一个模式，不切目标、不用通用包偷偷替代损坏的专属绑定。

## 当前模式资源

读取 `references/modes.md` 的通用部分及本次输入模式对应部分。具体参考数量、音频用途、模式和组合限制服从冻结目标能力；历史名称相似不等于能力或格式相同。

首尾边界与主体、环境参考按实际用途区分。参考音只能在目标实际接受的范围内用于音色参考或音轨复用，不能互换；无音频生成能力时保留原文声音意图并说明限制，不承诺已生成声音。编辑和延长表达原片修改或接续，不改成多参考拼接。

资源迁移自本项目已有表达规则，经独立整理，并非厂商官方指南原文。

## 评审与交付

按本次请求给定的结构和字段闭集返回结果，不另造业务 JSON、编号、错误码或工具。程序只校验必要结构、输入闭集中的真实引用、真实目标能力、权限及数据安全。缺少输入时说明具体缺口，不编造素材、来源或身份，不静默切模型或输入模式。

写作顺序、标签、模板、表达语言建议、画面质量与语义保真评审均为建议，不把评分或写法偏差作为保存、提交的前提。评审问题按应用实际提供的结构化枚举和引用记录；没有该结构时用明确的建议说明，不伪造“通过”。不因评审未完成自动重写、重试、删稿或隐藏成果；保留原稿和新版本，明确已评审或未评审状态。原文对白、旁白、歌词和画面文字逐字保留，不翻译、不润色，不用概述代替。
