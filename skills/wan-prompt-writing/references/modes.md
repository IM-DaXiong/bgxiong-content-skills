# 万相按模式表达

本附件只补充本次目标格式投影的表达方法。片段初稿按调用方自己的合同交付，不要求先建场次、故事板或静帧；已有多镜头只表示片段内部的切换。参考用途来自真实绑定，普通图片没有固定首尾身份。写法、版面和质量评审均为建议，不因评分自动重写或拒存；真实结构、资源引用、目标能力和安全仍按应用合同校验。

只读「所有模式」和当前输入模式那一节。模式是否可用、参考数量与组合限制以应用下发的目标能力快照为准；快照明确声明不接受当前模式时，按调用方提供的结构报告「模式不符」；未提供快照时说明能力未知，不猜测为不支持。

## 所有模式

- 正文里不写任何引用标记、分镜标题或时间码；用到哪条参考，就把它的参考用途 id 列在对应的那一行。
- 图像、视频、音频三类参考各有各的用途，不能互相改写：音频不能写成图像，视频不能写成多张图片。
- 首帧、尾帧这类「严格画面」与主体、场景、视频、音频这类「参考素材」是两种不同的输入方式，不能在同一次表达里混用。两类同时下发、而快照没有声明可以组合时，在冲突列表里写「模式不符」。
- 参考音的两种用途：
  - **音轨复用**：这段音频就是成片声轨，画面里的口型和动作跟随它；不要把音频里的内容再写成新台词。
  - **音色参考**：用这个音色说母版里的台词；不要把它当成整段成片声轨。

## 文生视频（text_to_video）

- 没有参考素材。第一行先写主体是谁和他的关键动作，不先写人物背景介绍。
- 正文里不出现任何参考相关的说法。

## 首帧图生（image_to_video）

- 首帧图是画面的起点。第一行列出首帧的参考用途 id，正文从这一画面开始写后续发生的变化。
- 母版没写的外观不要根据首帧图补写。

## 首尾帧（first_last_frame）

- 写清从起点到终点的过渡过程：先发生什么、再发生什么，结尾停在与尾帧一致的状态。
- 首帧的参考用途 id 列在开场的那一行，尾帧的参考用途 id 列在收尾的那一行。

## 仅尾帧（last_frame_only）

- 从合理的起点写起，过程逐步走向尾帧，最后一行落在与尾帧一致的状态，并在这一行列出尾帧的参考用途 id。
- 起点只能用母版里有的事实，不要为了凑出起点而编造情节。

## 参考生视频（reference_to_video、multi_image_to_video）

- 图像参考用来锁定主体或场景：主体或场景每次出现，都在那一行列出它的参考用途 id。
- 有参考音时，必须在台词或声音所在的那一行列出对应的音频参考用途 id，不能漏掉，也不能写成图像。
- 这个模式里参考音只能作为**音色参考**。应用下发的参考音标为音轨复用时，在冲突列表里写「参考用途不支持」，不要改成别的用途。
- 视频参考只按应用下发的用途表达（例如参考其中的角色或动作），不要改写成编辑或延长。

## 编辑已有成片（快照声明了编辑能力时）

- 正文写成对这段成片的修改：改什么、保留什么，按母版事实表达。
- 不要写成多图参考拼接，也不要写成「参考这段视频重新生成」。

## 延长已有成片（快照声明了延长能力时）

- 写明是在这段成片之后接着发生的内容，并按母版事实写出接续的动作和画面。
- 不要重写原成片已有的内容，也不要写成另起一段新视频。
