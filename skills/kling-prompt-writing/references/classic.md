# 可灵经典版参考

本附件只补充本次目标格式投影的表达方法。片段初稿按调用方自己的合同交付，不要求先建场次、故事板或静帧；已有多镜头只表示片段内部的切换。参考用途来自真实绑定，普通图片没有固定首尾身份。写法、版面和质量评审均为建议，不因评分自动重写或拒存；真实结构、资源引用、目标能力和安全仍按应用合同校验。

只有应用把当前目标绑定为可灵经典版时才读取本文件。它补充 `SKILL.md` 的共用方法，只写经典版的能力边界和表达要点；引用标记、分镜段落与时长语法由适配器编译，这里不写。

## 能力以快照为准

经典版不同型号支持的模式并不相同：有的支持文生、首帧图生和首尾帧，有的只支持文生和首帧图生。一律以应用下发的目标能力快照为准，不按型号名自行推断，也不写死参考数量或提示词长度。

## 参考用途

- 经典版的参考以图像为主，用作首帧或首尾帧；快照声明了的其他用途才可以使用。
- 应用下发的参考用途不在快照声明范围内时（例如视频参考、音频参考、待编辑视频、多主体参考），在冲突列表里写「参考用途不支持」，并列出对应的参考用途 id。不要把它改写成别的用途，也不要当作没看到。
- 本文件没有、快照也没有声明的参考写法，一律不用。

## 按模式表达

### 文生视频

- 没有参考素材。第一行先写主体是谁和他的关键动作，不先写人物背景介绍。
- 正文里不出现任何参考相关的说法。

### 首帧图生

- 首帧图是画面的起点。第一行列出首帧的参考用途 id，正文从这一画面开始写后续发生的变化。
- 母版没写的外观不要根据首帧图补写。

### 首尾帧

- 写清从起点到终点的过渡过程：先发生什么、再发生什么，结尾停在与尾帧一致的状态。
- 首帧的参考用途 id 列在开场的那一行，尾帧的参考用途 id 列在收尾的那一行。

### 快照没有声明的模式

编辑已有成片、延长已有成片、多参考生成等模式，快照没有声明时，在冲突列表里写「模式不符」，不要改写成快照里有的模式。

## 官方结构对照

以下对照 Kling 官方 quickstart（Text-to-Video / Image-to-Video Prompt Guide），只指导如何把母版事实写进已有表达合同，不新增私有字段、不改适配器协议。

### 文生视频（官方公式）

`Subject + Subject Movement + Scene +（Camera Language + Lighting + Atmosphere，可选）`

- **Subject / Subject Movement**：第一行写清主体是谁及其关键动作；外观细节用短句补在主体之后，动作须适合短片时长。
- **Scene**：动作之后写环境（前景/背景），保持简洁，能在短片内看清即可。
- **Camera / Lighting / Atmosphere**：仅当母版已有摄影语言、光影或氛围事实时写入对应维度；母版没有则省略，不套“电影级/氛围感”空词补全。
- 官方提示：用简单句式；视觉内容保持短片可完成；复杂物理轨迹（弹跳抛物等）当前模型难稳定生成，母版没有就不要发明。

### 图生 / 首帧（官方公式）

`Subject + Movement`（图已提供场景，不重述画面里已有的环境）

- 写主体及其运动；多主体时按主体逐条列出运动。
- 母版没写的外观不要根据首帧图补写。
- 官方提示：运动宜符合画面里已可能发生的物理；显著偏离画面的描述容易触发切镜或转场。

## 镜头与声音

- 母版有多个镜头时按镜头组织行；是否以多镜头方式提交、分镜怎么写，由适配器决定。
- 声音事实照常写进正文。是否生成声音是提交参数，不在正文里写开关。
