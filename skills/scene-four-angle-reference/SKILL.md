# 场景四视角

以剧集、片段上下文、用户描述及实际参考为依据，表达同一地点的结构、固定陈设、材质、时间和光照。环境是普通图片的本次用途，不要求创建场次或旧场景记录，不携带固定首帧、尾帧或角色身份。

## 按本次用途输出

- `clip-environment-prompt`：按调用方当前合同生成环境普通图片提示词。数量和环境选择由本次输入决定；不能因为本技能名称而强制四图、要求旧 sceneId，或自动发图片任务。
- `optimize-image-prompt`：忠实整理当前图片描述或编辑要求，保留用户的主体、文字、风格和真实引用，不擅自变成四向批量任务。
- `multi-view`：仅当用户选择四向模式时，读取 `references/layout.json` 的 `view4`，按已有槽位输出正面、左侧、右侧和背后。分张每张只写当前方向，合成读取现有 `sheet.view4`。画幅服从工作台选择，不静默改变模式、模型或张数。

## 空间表达建议

以入口或主立面确立正面，左右保持世界空间方位；内景观察同一空间四面，外景观察同一地点。相机转向时建筑、门窗、固定物体及光源保持空间连续，可见物体随遮挡自然变化，不要求所有物体每张重复出现。

保留用户给出的材质、色彩、天气、季节、时代和画面风格。遮挡面需要设计时说明是推断，不宣称从参考中读到了不可见细节；不增加原文没有的人物、剧情或标注。已有用户文字与元素完整保留。

## 执行与结果

仅在用户本次选择该参考方法和出图模式时，按 `references/layout.json` 的实际 `views`、`slotDetails` 和 `sheet` 组织结果。槽位 ID、所选子模式及输出结构由现有多视角执行合同读取，不自行增减、补造未支持的模式或把名称里的数字当成视频取帧数量。缺少对应单图布局时说明具体不支持的模式，不静默切换出图方式。

参考表是可选的独立图片创作方法，不要求先有故事、剧集、场次、故事板、片段稿或整套参考图，也不把它作为后续视频的前置。输出图片是普通素材；后续身份、外观、风格或边界用途由真实引用绑定决定，不能根据生成顺序自动当作视频首尾帧。

使用已经给出的描述、图片和确认参数，不因没有参考图拒绝合法的描述创作。参考图存在时只读取真实素材；无法读取时明确说明，不猜细节、不偷偷去掉参考。模型、画幅、出图方式与张数服从本次工作台冻结参数，已授权的选择不重复要求确认。

取景、身份一致、无文字等均为所选参考方法的创作建议。用户明确的风格、文字或其他要求优先，不强制写实、固定比例或摄影器材。仅程序必需的槽位结构、真实引用、权限和数据安全按机器合同校验；画面偏差和质量评审给建议，保留已生成结果与独立版本，不按评分拒存、不自动重写或重试，不伪造评审完成。
