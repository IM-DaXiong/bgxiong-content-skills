# 动作打斗提示词

## 片段与素材边界

片段从完整剧集或用户当前稿件出发，可以包含一个或多个连续剪辑镜头。镜头只表达片段内部的叙事次序，不要求先创建场次、故事板、静帧或逐镜业务记录。时长、镜头数和参考图数量以用户意图及本次冻结能力为准，不固定秒数，不要求先生成六张或九张图片。

图片是普通素材。人物外观、环境、风格、整片首尾或片内镜头边界等用途来自本次明确绑定；不能根据节点名、图片排列或画面猜测首尾。无参考图的合法输入也能完成内容表达。环境描述不要求一个旧场景实体，也不把环境图当成视频首帧。

本包只提供创作方法，只使用本次实际提供且已获授权的工具，不自行注册或调用其它能力。是否生成图片或视频由本次授权与实际可用工具决定，文字任务只交稿。

## 动作表达

以本次提供的剧集、当前稿件和真实参考为依据。用户没有动作内容时忠实处理原有内容，不把行走、交谈或拥抱改成战斗，也不默认武侠风格。只有本次请求允许创作扩展时，才在允许范围内补充表现细节，并按调用方合同登记推断；不得把选中技能当成任意加戏的授权。

- 明确来源中谁对谁做什么。沿用稳定称呼，写清发起者、目标、动作部位、站位和方向；人数由内容决定。
- 保持已有的先后、因果和空档。攻击、格挡、闪避、假动作、停顿、脱离都可成立；不为套完整连招补结果、伤害或胜负。
- 持械种类、持有者、换手、距离和使用方式归来源，不自行加入兵器或招式相克规则。
- 力度与表现服从用户风格。保留已有写实或幻想意图，不强加流血、骨折、击飞、火花、冲击帧、闪白或慢动作。
- 机位、景别和运镜服务已有内容。片段可一镜到底，也可在叙事需要时切镜；连续动作内部的阶段不必拆成多个镜头，不按台词行或固定秒数机械拆分。
- 保留总时长、约数、事件时间及速度变化。参数与内容时间冲突时给协调建议，保留完整稿件，不删除事件。
- 保留原有声音、对白和否定要求。未提供音效、配乐、字幕或旁观者时，不为增强冲击感自行增加。

## 阶段输出

片段初稿用途直接生成应用要求的可生视频正文及相关结构；不能要求先输出一份母版、先过评审或先有图片。视频内容整理用途按调用方当前合同返回事实、引用或正文。仅在调用方确实要求格式适配时才使用目标模型语法，不能把一种输出套给所有阶段。

## 评审与交付

按本次请求给定的结构和字段闭集返回结果，不另造业务 JSON、编号、错误码或工具。程序只校验必要结构、输入闭集中的真实引用、真实目标能力、权限及数据安全。缺少输入时说明具体缺口，不编造素材、来源或身份，不静默切模型或输入模式。

写作顺序、标签、模板、表达语言建议、画面质量与语义保真评审均为建议，不把评分或写法偏差作为保存、提交的前提。评审问题按应用实际提供的结构化枚举和引用记录；没有该结构时用明确的建议说明，不伪造“通过”。不因评审未完成自动重写、重试、删稿或隐藏成果；保留原稿和新版本，明确已评审或未评审状态。原文对白、旁白、歌词和画面文字逐字保留，不翻译、不润色，不用概述代替。
