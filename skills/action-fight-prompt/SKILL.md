# 动作打斗提示词

## 从原稿取出必须拍到的事

先在心里把场面说成一句连续的话，标清谁发起、谁承受、哪些动作落空或成功、最后必须看见什么。动作词顺序可按因果重排，用户指定的先后优先。人物、接触对象、明确的结果和对白原语言贯穿成稿。不得新增招式、伤势、胜负、落地或旁人接应，结尾发生的事以原稿或动作清单为限。保留总片长、声音条件及用户明确锁定的镜头、焦段、机位或卡点。整场改写时，旧镜号、旧切点和原有摄影说明都可以重新设计。翻译、局部润色、保留某镜等请求按指定范围处理；没有打斗就沿用原意。

参考图按原绑定使用，保留引用的拼写、次数和归属。人物图维持外观，场景图维持地标关系。姿态、机位或构图图只约束对应瞬间，让表演自然进出；指定某秒的焦段就写在实际覆盖该秒的画面里。明确要求定格时才停住。

## 先连动作，再决定从哪里看

先想象两个人同处一个连续画面。让上一拍留下的位置、方向或可见状态成为下一拍的起点。同一动作的准备与结果可以一气呵成，双方关系改变时给观众辨认的时间，接着让目光顺着运动看到去向。只有几个动作词时，先用一个双人镜头试写到底，确需换视点再拆。比如“甩飞、踢脸、抬腿、抓住腿”可串成：甲抬腿踢中乙的脸，乙接住甲尚未收回的腿，将甲甩飞。此例只示范动作归属。有其他角色或结果就依原稿；补衔接仅需位置与表演，避免增写另一轮交锋。场面中的接触距离须前后相容。

先选能同时看清人物关系和运动方向的取景，把原稿结尾确实用到的地标提前纳入画面。当前镜头看得清下一拍，就接着拍。决定切镜时想清新机位让观众多看到什么，例如原景别装不下完整的运动轨迹。可以跟移或拉开，也可以切远景。换角度用同一地标或连续运动接上；越轴时让观众看见视点过轴或重新建立方位。只有主观体验提供关键信息或用户明确锁定时才转主观；在该视野中只写角色能看见的变化。掌心遮住动作、贴脸看不见双方关系时，重新取景。

一段只写最能读出的变化。连续交锋可以很快，转折或终结运动留到观众看清。用身体轮廓、人物间距离和去向表现冲击，把反复转腕、指尖摩擦、逐寸挪脚压成一次清楚的画面反馈。点名的接触拍到可见结果。只说“甩飞”就拍清谁把谁甩离原位、人物飞向何处，镜尾仍在空中。原稿另有路径、地标或末帧构图时，让同一次运动完整经过指定位置并抵达末帧。此处收镜。

## 写成可直接使用的分镜

按原稿语言和调用方格式交付新画面，每个实际镜头写清取景、可见变化和镜尾状态。有片长就从零连续排到总长，按观看需要分配秒数；没有片长可用相对节拍。若必须保留编号，原位改写各编号后的机位和画面，相邻编号可以接续同一镜的运动。每个时间窗只出现一次。直接替换旧拍法，避免把另一版镜头接在旧描述后面。选段只改本段所属事件，沿用在整场中的时间和进出状态，邻段仅供衔接。若给到的正文从某镜中间开始，直接续写该动作，只在本段拥有镜头开头时标镜号和时间窗。提要和诊断只在要求时单独输出。

交稿前把镜头在脑中过一遍：哪一个动作还没看清就被切走？哪个切点前后看见的是同一件事？哪里只剩两个人原地反复动手？据此调整切点、时长或取景，再核每个关键动作的归属、成败和最后一帧。
