# LTX-2.5 按模式写法

本附件只补充本次目标格式投影的表达方法。片段初稿按调用方自己的合同交付，不要求先建场次、故事板或静帧；已有多镜头只表示片段内部的切换。参考用途来自真实绑定，普通图片没有固定首尾身份。写法、版面和质量评审均为建议，不因评分自动重写或拒存；真实结构、资源引用、目标能力和安全仍按应用合同校验。

只应用冻结模式对应的一节；未知、旧版或多图模式不能套用I2V。

## 图生视频（image_to_video）

首帧是外观事实来源。简短指认主体后，重点表达接下来的动作、表情、运镜、光线变化与声音，不重复堆砌静态外观，不引入主要新人物或改变服装。原稿要求元素从画外进入时交代空间关系。与首帧矛盾时按合同报告，不静默改稿。

## 文生视频（text_to_video）

以原稿建立稳定人物指认、动作和空间关系。缺失的表现细节仅在允许扩写时补足，按合同登记新事实；不凭空补台词或主要事件。多个人物始终使用稳定视觉标识。

## 首尾帧（first_last_frame）

首帧与尾帧都是外观事实来源：首帧在 0 秒，尾帧在结束时刻。重点表达从首帧画面到尾帧画面的连续变化，包括主体动作、机位或景别移动、光线与环境过渡及声音，使过程能自然抵达尾帧；不重复堆砌两张图的静态外观，不在中途引入两张图都没有的主要人物或换装。原稿与首尾帧矛盾时按合同报告，不静默改稿。

## 通用

表达语言服从冻结语言；对白、歌词与画面文字保持原语言逐字。按时间组织为连贯段落，不加镜头标题、引用token或时间码。长度随事实和引用决定，无统一200词限制。用户要求静音/画面文字时保留该意图；负面结果不得与之冲突。
