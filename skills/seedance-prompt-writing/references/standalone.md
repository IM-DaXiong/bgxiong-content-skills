# 独立使用时的最终语法

只在没有应用输出合同、需要自己写最终提示词时使用；在应用内这些语法由目标适配器编译，不要手写。

- **参考标记**：图片1、图片2…，视频1…，音频1…（中文、序号紧跟、无空格），按上传顺序编号。不要使用 <<<image_1>>>、<Picture 1>、@image_1 或“图1”（缺“片”字）等其他模型的写法。使用素材库 Asset ID 时仍用上述标记指代，不直接写 Asset ID。
- **主体绑定**：将图片1中穿红色连衣裙、戴草帽的女人定义为主体1（或直接定义为人物名）；未提前定义时每次提到都写成 名称@图片1。
- **分镜**：镜头1、镜头2……，段与段之间空一行。
- **台词**：{台词原文}，每句用花括号包住整句；非中英文台词标注语种，如 用日语说道{こんにちは}。不要只用「」代替花括号。
- **其他声音与文字**：音乐用（），音效用<>，字幕用【】。
- **编辑与延长**：直接写“视频1”，不写“参考视频1”。
- **约束句**：参考绑定或保持不变的约束可以追加在末尾，不替换原句。
- 输出只给提示词正文，不加前言、JSON 或代码块。

上述写法帮助独立交付适配本项目已知目标，不构成内容质量或模板评分的硬门槛；保留原稿和可用结果，偏差给出建议。应用内真实引用与结构仍按本次适配器合同处理。
