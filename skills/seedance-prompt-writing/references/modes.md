# Seedance 各模式写法

本附件只补充本次目标格式投影的表达方法。片段初稿按调用方自己的合同交付，不要求先建场次、故事板或静帧；已有多镜头只表示片段内部的切换。参考用途来自真实绑定，普通图片没有固定首尾身份。写法、版面和质量评审均为建议，不因评分自动重写或拒存；真实结构、资源引用、目标能力和安全仍按应用合同校验。

每节独立；只读当前模式需要的一节。所有小节都服从 SKILL.md 的「边界」：只表达母版事实，不新增、删改或调序。

## 文生视频

- 没有画面参考，主体外观全部来自母版文字：主体第一次出现时写全母版给出的稳定特征，之后用同一称呼。
- 组织顺序：主体与动作 → 场景环境 → 光影色调 → 运镜 → 风格与画质 → 约束。母版没有的要素直接省略，不补齐公式。
- 多镜头按镜头1、镜头2……分段，每段写清谁、在哪、做什么、镜头怎么动、听到什么。

## 首帧／尾帧图生

适用 image_to_video、first_last_frame、last_frame_only。

- 关键帧画面已经给定外观、构图和场景，不要把画面里已有的外观再改写成别的样子，也不要写与关键帧冲突的内容。
- 首帧（image_to_video）：从首帧画面出发，写之后发生的动势与变化，时间向后发展。
- 首尾帧（first_last_frame）：写从首帧到尾帧之间连续、合理的过程，结尾自然落到尾帧画面；不在中间跳出两帧都没有的场景。
- 仅尾帧（last_frame_only，仅当目标声明支持）：写一个与母版一致的起始状态，过程向尾帧收束，结尾落到尾帧画面。
- 母版要求锁定不变的主体或建筑，写成明确的“保持不变”约束，不留给模型自由发挥。
- 上述规则不要求删除母版已有的首帧场景、构图、外观或状态事实，也不允许根据图片自行扩写；应用已提供的每个事实仍按原意表达。参考主体绑定与保持身份的专用句由程序编译。

## 多图与多模态参考

适用 multi_image_to_video、reference_to_video。参考素材用来锁定外观、空间、动作、运镜或风格，不是要剪进成片的素材。

- **先定义主体。** 只用母版已经给出的稳定特征区分对象，不凑特征数量。应用内主体绑定句由程序生成，正文保持母版称呼，不自行发明主体名或重复绑定语法。
- **按用途说参考。** 句式取决于母版写明的用途：
  - 主体／外观：参考某图中的某主体，生成画面描述，保持该主体特征一致。
  - 场景／风格：场景设定在某图中的场景，或整体风格参考某图。
  - 动作：参考某视频的动作，生成画面描述，保持动作细节一致。
  - 运镜：参考某视频的运镜，生成画面描述，保持运镜一致。
  - 特效：参考某视频的特效，生成画面描述，保持特效一致。
- 参考视频在这里只提供动作、运镜、特效或风格，不写成“对这段视频进行剪辑”。
- 空间关系优先交给参考图表达，正文只写母版中关键的相对位置。
- 每个参考按母版用途使用一次说法即可，不重复堆叠同一参考。

## 视频编辑

仅当目标声明了视频编辑任务时使用。被编辑的视频就是成片底稿，不是参考。

- 直接指代被编辑的视频，不要写“参考某视频”，否则会被误判为参考生成。
- 增加：写清新增元素的特征、出现时机、出现位置。
- 修改：严格编辑该视频，把其中的某特征改为母版给出的新特征。
- 删除：点明要删除的元素，并强调其他内容保持不变。
- 未提及的部分默认保持不变；母版要求保持的元素可以显式重申。
- 同时参考另一素材时：参考某图或某视频的某维度，严格编辑被编辑的视频，再写具体编辑内容。

## 视频延长

仅当目标声明了视频延长任务时使用。素材里的视频就是被延长的片子。

- 写成向前或向后延长该视频，或生成该视频之前／之后的内容，再写需延长部分的内容；不要写成全新的参考生成。
- 延续原片的主体、风格、声音与叙事，不重复原片已有片段。
- 多段衔接（轨道补齐）：视频1 + 过渡画面描述 + 接视频2 + 过渡画面描述 + 接视频3；段数和总时长以目标当时能力为准。

## 参考音频用途

有参考音频时按母版标注的用途二选一，不能混用：

- **音轨复用**：该音频全程作为成片声轨，口型跟随该音频；不要再另写一段台词让角色念。
- **音色参考**：用该音频的音色说母版里的台词；不要原样播放参考音频。母版若描述了音色特征（如低厚温润的中年男声），可一并写出以帮助还原。
- 不写“原样（exactly as it is）”一类含混说法，用途必须写清。
