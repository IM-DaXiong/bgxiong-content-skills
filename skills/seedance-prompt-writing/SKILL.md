# Seedance 视频提示词

本技能只管“怎么说”：把一份已经确定的视频内容（下称母版：镜头、事实、逐字台词与画面文字、参考素材及其用途）写成 Seedance 容易理解的提示词。它不负责重做剧情规划；母版在这里指本次冻结的视频内容，不表示审阅必须先通过。

## 片段与素材边界

片段从完整剧集或用户当前稿件出发，可以包含一个或多个连续剪辑镜头。镜头只表达片段内部的叙事次序，不要求先创建场次、故事板、静帧或逐镜业务记录。时长、镜头数和参考图数量以用户意图及本次冻结能力为准，不固定秒数，不要求先生成六张或九张图片。

图片是普通素材。人物外观、环境、风格、整片首尾或片内镜头边界等用途来自本次明确绑定；不能根据节点名、图片排列或画面猜测首尾。无参考图的合法输入也能完成内容表达。环境描述不要求一个旧场景实体，也不把环境图当成视频首帧。

本包只提供创作方法，只使用本次实际提供且已获授权的工具，不自行注册或调用其它能力。是否生成图片或视频由本次授权与实际可用工具决定，文字任务只交稿。

## 内容边界

1. **只表达，不加戏。** 母版没有的动作、神态、情绪、运镜、光影、风格、画质词、约束词、音效、音乐和台词一律不写。下文的写法建议只决定已有事实的措辞和顺序，不是新增内容的理由。
2. **不删、不改、不调序。** 每条事实都要表达到；不合并成改变含义的概括；镜头和事件按母版先后。确实无法在目标上表达的事实，明确报告冲突，不静默丢弃或改写。
3. **逐字内容原样保留。** 台词、歌词、画面文字、字幕不改字、不翻译、不润色。
4. **参考只用清单里有的。** 只指代母版素材清单中存在的图片、视频、音频，按清单写明的用途使用；不点名不存在的序号，不把参考用途换成另一种。
5. **输出语言**跟随目标要求（建议中文，服从本次冻结语言）；台词保持母版原语言。

## 在应用工作台内

应用会给出片段内容或内容整理产物、素材用途清单、目标模式和本次输出合同。以下表达行规则只用于调用方实际要求的格式投影，不能套给片段初稿；只要求正文时不发明业务 JSON。按合同输出：

- 每行声明它表达的是哪个镜头、哪些事实；台词与画面文字通过引用编号挂到行上，参考素材通过参考用途编号挂到行上。
- 台词原句由程序逐字插在该行正文之后，正文不用重复；说话人、电话来源、接听或听见、语气以及母版已有的口型、眼神、停顿仍是必须保留的事实，不能因为挂了台词引用就省掉。
- 行文里**不要自己键入**参考标记（如 图片1）、台词花括号、镜头段落标题或时间码。这些是 Seedance 专属语法，由应用的目标适配器按目标能力确定性编译；主体身份锁定句也由适配器加在正文前，不要重复。
- 行文中用母版给出的主体称呼指代人物与物体，保持全程一致，让适配器能把称呼与参考绑定对上。
- 遇到母版事实超出目标能力（模式不支持、参考用途不支持、母版信息不足），按合同报告冲突，不自行降级或补写。

## 通用写法

1. **主体先立后用。** 主体第一次出现时，只用母版已经给出的稳定静态特征（数量不限，不要求凑足）（服饰、发型、外观、类别）说清是谁；之后始终用同一称呼，多个主体各用唯一称呼，不用含糊代词，不出现矛盾特征。
2. **按镜头写时间轴。** 按母版已有的镜头和事件顺序逐行表达，不新增镜头，镜头标题由应用生成。同一时刻内可按运镜 → 主体动作与神态 → 空间关系 → 声音组织，但不能为了套顺序改变事实发生先后，也不能把之后才揭示的内容提前。
3. **动作写具体。** 落到手、腿、头、肩背等部位，写出母版给出的幅度、速度、力度，以及前后动作的衔接。情绪只在母版给了外在表现时写外在表现，不把“悲伤”自行扩写成新动作。
4. **运镜用标准术语。** 如中景、特写、全景、缓慢推镜、平稳横移、固定镜头。母版在同一镜头里有先后几种运镜，就按先后分句写；母版明确同时进行的组合运镜也应保留，不凭“一镜一种”删除事实。
5. **时间与节奏。** 母版若同时有细的秒窗和粗的总时序，以细秒窗分段，粗时序折进对应细段；不得把后文才揭示的内容提前。自然语言总时长、约数、精确事件时间都按母版保留；机器时间码包装由适配器生成。总时长与工作台参数不同或目标时长不支持，只需非阻断提醒协调，仍完成全部表达，不写 conflicts。
6. **声音。** 分清音乐、音效、人声台词和字幕四类，按母版逐镜头写；母版台词不改原语言，多语种台词照原文保留；正文表达语言服从应用合同。
7. **画面文字。** 写清文字内容、出现时机、出现位置、出现方式和文字特征（颜色、风格），全部取自母版；优先保留原字，不替换生僻字。
8. **风格、画质与约束。** 只转述母版已有的风格、画质要求和禁止事项（如无字幕、无水印、无 Logo），放在正文末尾。

## 动作与交互的表达

只表达母版已有的动作链，稳定区分施动者与对象，保留事件顺序、力度、反应与动作间的空档。不为增强打击感新增招式、伤害、命中结果或音效；没有命中、缺少连续招式或没有声音本身不构成遗漏。表达改进只作非阻断建议，真实事实冲突仍按应用的结构化审阅合同处理。

按母版已有镜头和时序写清动作与反应，主体称呼与冻结参考绑定一致。保留已有细秒窗，将粗总时序融入相应事件，不把连续动作拆成新增镜头。镜头标题、机器时间码、参考标记与逐字台词包装仍交由目标适配器编译。

## 按模式渐进读取

应用会把 `references/modes.md` 与本正文一起提供；只应用与当前模式对应的一节，其他模式不构成本次要求。独立使用时按需读取：

| 当前模式 | 读取小节 |
|---|---|
| text_to_video | 「文生视频」 |
| image_to_video、first_last_frame、last_frame_only | 「首帧／尾帧图生」 |
| multi_image_to_video、reference_to_video | 「多图与多模态参考」 |
| 目标声明的视频编辑或视频延长任务 | 「视频编辑」或「视频延长」 |
| 素材里有参考音频（任何模式） | 另读「参考音频用途」 |

## 独立使用

把本技能交给其他 Agent、没有应用输出合同时，直接写出最终提示词：先按上文写法组织内容，再读 `references/standalone.md`「独立使用时的最终语法」，由你自己写出参考标记、台词符号和镜头分段。

写法依据为火山引擎 Seedance 2.0 系列官方提示词指南（https://www.volcengine.com/docs/82379/2222480 ，以发布时版本为准）以及本应用此前 Seedance 优化中的指代、对白与模式规则，经原创改写为“只表达已定内容”的方法；不是官方原文，也不包含原指南中的创作扩写要求。

## 评审与交付

按本次请求给定的结构和字段闭集返回结果，不另造业务 JSON、编号、错误码或工具。程序只校验必要结构、输入闭集中的真实引用、真实目标能力、权限及数据安全。缺少输入时说明具体缺口，不编造素材、来源或身份，不静默切模型或输入模式。

写作顺序、标签、模板、表达语言建议、画面质量与语义保真评审均为建议，不把评分或写法偏差作为保存、提交的前提。评审问题按应用实际提供的结构化枚举和引用记录；没有该结构时用明确的建议说明，不伪造“通过”。不因评审未完成自动重写、重试、删稿或隐藏成果；保留原稿和新版本，明确已评审或未评审状态。原文对白、旁白、歌词和画面文字逐字保留，不翻译、不润色，不用概述代替。
