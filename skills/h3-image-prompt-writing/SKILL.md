# H3-Image 图片提示词

本包由比格熊项目独立编写，依据官方公开的图片提示词方法与引用语法适配当前优化入口。用户点击优化后，将成稿交给应用审阅与保存。

## 应用输入与输出

遵循调用方实际给出的输出结构，把成稿写入指定字段。模式、参考图集合及顺序、尺寸、种子和模型以本次工作台冻结输入为准。优化只交付提示词，生成由应用已有提交操作执行。负面提示词与其他工作台参数由宿主管理。

保留用户指定的人物、数量、动作、颜色、关系和排除要求。已有稿件按用户要求的范围修改。应用提供的片段内容作为创作上下文，输出描述本次目标静态画面。参考素材的用途按本次明确绑定理解。所选文本模型无法看图或图片不可读时，按应用现有结果结构交代具体缺口，保留有依据的部分。

## 文生图

采用自然连贯的英文画面描述，用户明确要求的输出语言优先。交代主体、可见动作、空间、构图、光线与材质，细节服务用户主题。用户给出的是简短构想时，可以在其授权范围内补全视觉细节；涉及真实数据、身份或已有素材的事实须有来源。

画内文字使用引号标识，逐字保留用户指定的语言、拼写和标点，并说明位置。只描述目标静态画面，检查数量、左右方位、遮挡、接触和视线是否一致。画幅建议服从工作台已选参数。

## 参考图编辑

先查看实际图片，按应用输入顺序引用 `<Picture 1>`、`<Picture 2>`。单图同样使用 `<Picture 1>`。图片编号保持与提交顺序一致，只使用本次存在的编号。

最终正文写成连续一段英文，依次组织来源对象定义、目标画面和各对象关系、改动细节。需要独立描述保留或借用关系的对象可以定义为 `<Subject 1>`、`<Subject 2>`，编号在全文保持一致。对象可以是人物、局部物件、背景或借用的属性，定义以实际可见信息为据。

目标概述从 `The target image` 开始。对完全保留的对象使用 `<Subject N> is fully preserved.`；局部改变时说明保留属性和变化属性；借用颜色、身份或风格时明确来源、接收对象与允许变化的范围。改色只改变颜色，复制需要说明增加实例，移动需要说明新的位置。

已声明保留的对象用 Subject 编号引用，后续集中描述变化。描述最终可见结果，避免反复重述未改区域。用户要求修改画面文字时，交付完整的新文字并保留其指定语言。核对背景、光线和主体关系是否与本次局部改动一致。

## 交付检查

确认 Picture 编号来自本次素材，Subject 定义与关系一一对应。检查用户事实、确切文字及数量是否完整，成稿与工作台生成模式一致。写作建议与质量评审由用户审阅，程序按现有合同处理结构和引用。保留原稿与优化后的新版本，并如实标明缺少图片或尚未评审的部分。
