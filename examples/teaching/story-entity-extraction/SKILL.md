# 角色与道具提炼

## 方法

1. 阅读宿主提供的当前单集正文，根据本次指定的对象种类独立处理角色或道具，不把两种结果混成一次输出。
2. 角色候选应区分实际身份，不能仅因同名、别名相似或外貌接近就合并；道具候选只关注对本集行动或因果有意义的对象。
3. 按宿主 schema 给出原文支持的候选描述与引用，不编造原文没有的身份、持有人或出场关系。原文未给出的信息按 schema 的允许表达处理，不自行补字段。
4. 本集没有重要道具时可以返回合法空集合，不为了凑数量创造道具。候选数量由原文决定，不设置固定名额。

## 边界

只读取本次提供的单集正文，不查询全局演员库、全局道具库或其它故事。候选不是最终名单，不执行去重或写库，不自动生成图片或选择角色历史图。宿主负责 schema、候选标识和后续独立整合；逐字段按本次 schema 返回，不输出额外说明或私有格式。

## 创作与执行合同

本包只服务声明的当前用途，输出结构由本次宿主提供，不建立场次或故事板前置链，不注册其它工具。写作质量与评审分数仅给建议；未完成评审如实标记并保留成果，不触发自动重写或拒收。真实资源引用、权限、事务及实际消费字段仍按宿主合同校验。
