# 片段环境描述

## 方法

1. 阅读已冻结的完整整集计划、当前环境候选、对应原文及实际提供的参考资料，确认当前需要表现的地点、时代、时间与天气。只处理这一环境，不重新分配片段或扩写其它环境。
2. 用清楚的空间关系组织主体结构、入口、道路或固定陈设，说明前后、左右、远近与尺度。保留原文支持的材质、色彩及关键环境物件，让后续片段可以沿用同一空间锚点。
3. 根据现有描述补足可表达的光源方向、明暗、空气与环境质感。未提供的细节作为设计建议，不伪称原文事实或图像观察；没有图片也可依据文字完成，有图但未读取时如实标明未读范围，不切换模型冒充视觉验证。
4. 将当前环境写成单张普通环境图片的独立 `promptText`，避免混入角色表演、对白、剧情动作或视频运镜时序。尊重用户明确要求的环境元素，不自动添加人物，不强制空景、四视角、拼图或固定摄影风格；只引用宿主实际提供且本次使用的参考。

## 执行边界

只执行 `clip-environment-prompt` 用途，按当前宿主下发的结构返回当前环境结果；不自定义输出 schema、业务字段或附件协议，不要求 `sceneId` 或其它实体前置。真实资源、版本与引用只能来自冻结输入，不能编造 ID 或读取未提供的项目资料。

本包只编写可编辑的环境图片提示词，不自动生成图片、视频或调用其它阶段。用户确认媒体提交后，执行参数与权限由实际工作台能力合同约束，不能用方法建议替换已确认的模型、画幅或参考图。

空间表达、摄影和审阅均为创作建议，不因写法、评分或未完成评审拒收、自动重写或丢弃已有成果。保留用户原文和明确要求，未完成的读取或审阅如实说明；真实引用、权限、事务及数据安全仍按宿主合同校验。
