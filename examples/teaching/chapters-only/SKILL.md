# 剧集创作

## 方法

1. 以本次宿主提供的故事原文为材料，保留其中明确的事件、人物关系和因果；额外约束只作用于本次创作。
2. 围绕人物目标、阻力和转折安排剧集顺序。每集写出可阅读的正文，让结果成为下一集的起点，避免只列一句大纲。
3. 用户给出的集数和每集时长是参考；没有正数参考时，依据原文组织，不自行套用固定集数、场数或镜数。
4. 修改已有剧集时，根据宿主提供的原稿与修改要求完成正文，不把原稿替换成摘要。生成与修改使用同一叙事方法。

## 输入和返回边界

只使用宿主提供的材料，不读取其它故事、全局演员或道具资产。宿主负责输出 schema、身份引用和保存；逐字段按本次 schema 返回完整结果，不增加方法自定义字段或 Markdown 包装，不截断用户材料。

本包只提供文字创作方法，不运行流程、脚本或工具，不生成故事圣经、角色名单、场次、分镜、图片或视频。其它阶段由用户在对应入口独立调用，本方法不自动启动它们。

## 创作与执行合同

本包只服务声明的当前用途，输出结构由本次宿主提供，不建立场次或故事板前置链，不注册其它工具。写作质量与评审分数仅给建议；未完成评审如实标记并保留成果，不触发自动重写或拒收。真实资源引用、权限、事务及实际消费字段仍按宿主合同校验。
