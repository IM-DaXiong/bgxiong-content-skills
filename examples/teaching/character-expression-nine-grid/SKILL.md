# 角色表情九宫格

给同一个人物准备可选的正面半身表情参考：同一张脸、同一发型、同一服装，只有表情变化。适用于用户选定的定妆参考，不作为视频前置，也不要求先写满九条模板。

机器可读的槽位顺序、各槽提示词要素、单图合成的整表描述都在 `references/layout.json`，本文件只讲怎么用。需要精确数值或原文时读取该资源，不要凭记忆复述。

## 调用前要准备

- 一张可作为身份参照的人物图或人物描述（脸型、发型、服装）。没有参考图时可依据本次人物文字描述设计，不声称已读取不存在的图像。
- 视角数量：九视角得到全部九个表情；三视角只取前三个表情；四视角只取前四个表情（顺序见 layout 的 `views`）。
- 出图方式：**分张批量**（每个表情一张图）或**单图合成**（九个表情合成一张表）。使用工作台已确认的模式；尚未确认时先展示方案。
- 画幅：分张批量和单图合成都使用工作台所选比例；按该画幅安排参考板，不规定固定横竖比例。可选比例仅受所选模型能力限制。

## 九个表情

第一个表情“平静”是身份锚点（layout 的 `identityAnchor`），其余表情都以它的脸为准。

| 顺序 | 槽位 | 中文 | 要点 |
|---|---|---|---|
| 1 | calm_neutral | 平静 / 面无表情 | 眉放松，双唇轻闭，直视镜头，克制 |
| 2 | joyful_smile | 开心 / 灿烂笑容 | 眼微眯，脸颊上提，自然露齿 |
| 3 | angry | 生气 / 愤怒 | 眉紧皱，目光锐利，双唇紧抿，克制但有力 |
| 4 | wronged_tearful | 委屈 / 想哭 | 内侧眉上扬，眼含水光，下唇微颤 |
| 5 | surprised | 惊讶 / 震惊 | 眼睛睁大，眉高抬，嘴微张 |
| 6 | confused | 疑惑 / 不理解 | 单侧眉微抬，嘴微张，头微歪 |
| 7 | coquettish | 撒娇 / 可爱 | 脸颊微鼓，眼睛明亮，嘴唇轻噘 |
| 8 | disdain | 鄙视 / 无语 | 半垂眼，单侧眉微抬，嘴角微斜，侧目看镜头 |
| 9 | smug_smile | 得意 / 坏笑 | 单侧嘴角上扬，眼微眯，带点调侃 |

每一格的完整英文提示词要素（朝向、取景、后缀、负面项）在 layout 的 `slotDetails`。

## 两种出图方式

- **分张批量**：每个槽位一张正面半身图。提示词只描述这一格的取景和表情，**不要**写成九宫格，否则每张图都会画出一张拼图。
- **单图合成**：只在九视角下可用。整表描述取自 layout 的 `sheet.view9.layout`，另有参考图前言和质量尾句。九格按从左到右、从上到下的顺序排列，顺序与上表相同，各格表情要有明显区分，身份一致。

## 限制

- 三视角、四视角**没有**单图合成描述。用户选了三/四视角又要单图合成时，明确告知做不到并请用户改成九视角，或改成分张批量；不要擅自补一段整表描述，也不要静默改成别的方式。
- 不改变人物的服装、发型和脸；不加入多余人物。
- 本方法不自己点击生成；提交采用工作台已确认的视角数量、出图方式和画幅，不重复索要同一确认，提交后不静默改动。
- 带参考图的生成失败时如实报告，不要降级成不带参考图再生成。

## 调用后应看到

- 单图合成：1 张表情表，九格都是正面半身，表情明显不同，身份一致，没有文字和水印。
- 分张批量：与视角数量相同的图片数量；每张都是同一人物的正面半身；画廊里按上表的中文名或槽位标注。
- 如果结果里有人脸漂移、服装变化、多出人物或出现文字，如实说明哪一格有问题，建议重出该格。

## 当前创作边界

槽位、子模式与引用按实际多视角执行合同处理，图像布局数量不是视频镜数限制。人物一致性、摄影与表演质量是创作建议；出现偏差时说明具体问题并保留成果，不因评分硬拒或自动重写。尊重用户媒介风格，不添加固定摄影控件要求或启动未发布工具。
