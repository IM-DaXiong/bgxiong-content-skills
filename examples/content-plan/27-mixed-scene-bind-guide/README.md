# 案例27 · 混绑验收说明包

## 这个 Skill 控制 LLM 返回什么格式
验收步骤包：不要用它替代 25/26。返回格式同案例 21。

## 字段表（只列本包用到的）
同案例 21。本 README 的用法才是重点。

## 你可以改什么 / 不要改什么
不要改成生图策略。不要指望入口 Skill 顶未绑场。

## 用户怎么用（导入 → 绑定到哪 → 点哪个按钮）
1. 导入 25 和 26。2. 武打场绑 25，文戏场绑 26。3. 分别生成，日志里 planHash 应不同。4. 未绑场走官方 native.content.plan，不是入口 Skill。

## 不合格时你会看到什么（人话）
hash 漂移会要求重绑。未绑走官方默认，不提示必须上传 Skill。

## 拷给其它 LLM 时如何改成自己的包（3 步）
1. 复制本目录，改 skill.manifest.json 的 id（必须 local. 开头）和 displayName。
2. 只改 pipeline.json 里本 README 允许改的字段（枚举、字数、镜数）。
3. 设置 → 创作智能体 → Skills 库 → 导入包；在场次工作台绑定后再点生成分镜。
