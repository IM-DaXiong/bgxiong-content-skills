# 案例11 · 九槽含眼睛与衣服特写

## 能做什么

- `view9` 最后两槽是自写 `eye_closeup` / `garment_closeup` 四臂。
- 落盘 suffix 为这两个 slotId；重试按 slotId，不会回退官方角名。

## 不能做什么

- 不能用单图九宫格 sheet（与官方默认不是逐字匹配）。
- 第 0 张仍是身份锚，不要改成特写。

## 点哪个按钮

演员定妆工作台 → 选 9 视角 → 生图策略选本包 → 开始生成。

## 跑完应看到什么

共 9 张：前 7 张官方转身角 + 眼睛特写 + 衣服特写。画廊标签对自定义槽显示 slotId。
