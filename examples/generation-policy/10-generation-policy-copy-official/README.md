# 案例10 · 原样复制官方槽

## 能做什么

- 导入后出现在生图工作台「生图策略」选择器（capability = `generation.policy`）。
- 槽数与四臂与官方默认一致；未改 framing/suffix。
- 用来证明：能装、能绑、出图行为与「官方默认」相同。

## 不能做什么

- 不会创建 `ai_task`，点导入不算开始生成。
- 不是内容编排包：生成剧集选择器里看不到它（没有 `content.plan`）。

## 点哪个按钮

1. 设置 → 创作 Skills → 导入包 → 选本文件夹。
2. 演员定妆 / 角色定妆 / 场次概念 / 道具或场次资产工作台 → 生图策略选本包。
3. 再点「开始生成」。

## 跑完应看到什么

- 3/4/9 视角张数与未绑 Skill 时相同。
- 单图合成（sheet）仍可用（槽与官方逐字一致）。
