# 导入和执行时常见问题

- 缺少 `SKILL.md`：目录或 ZIP 还不是技能包。
- frontmatter 无法解析：补上开头和结尾的 `---`。
- `name` 与目录名不同：两边改成同一个小写连字符名字。
- 用途为空或不在快照中：当前作者检查会拒绝；不要自造用途 ID。
- 没有 `clips-v1`：导入阅读可以成立，当前执行不可用。检查器把这种情况标为工作流不匹配，而不是把文件判成损坏。
- 引用了不存在的相对路径，或路径包含 `..`：拒绝，并且不把文件写到包外。
- `layout.json` 不是对象，或身份锚不在视图清单第一位：布局检查失败。
- 替换时摘要和预览不一致：保留已安装的旧版本，重新导出再导入。

这些诊断不要求改写安全合同，也不要删除失败的原稿。
