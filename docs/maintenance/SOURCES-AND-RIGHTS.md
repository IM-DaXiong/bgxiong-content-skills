# 来源与权利

仓库根 `LICENSE` 保持原有自定义许可，不改成 MIT 或 Apache。

从主仓内置目录原样复制到 `skills/` 的包，来源记在 `import-inventory.json` 的 `sourcePath` 与 `sourceDigest`。视频提示词包在主仓资源清单中标记为项目迁移改写，不是上游技能仓库的原样文件。本次把它们收进源码树，公开再分发仍以根许可和该清单备注为准；本轮没有把 ZIP 发到 GitHub Release。

`h3-prompt-writing` 即使在主仓资源清单里写了项目编写，作者规则仍要求 `blocked_pending_legal`。本仓库不复制该包，不写案例，不提供下载。

尚未逐张核对真实人物照片或第三方素材的包，不能把样例状态写成已授权公开。当前讲解页的样例状态都是待制作。
