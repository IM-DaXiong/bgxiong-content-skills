# 混合叙事片段方法

状态：`teaching`。版本：`1.0.2`。工作流：`clips-v1`。包目录：`examples/teaching/clip-method-selection`。

## 用途

为同集动作、文戏与环境过渡选择适合的表达方法，保持统一剧情与空间连续性。

## 适用场景

正在使用比格熊创作工作台、并选择了上述用途的作者。 声明用途：episode-clip-plan、clip-video-draft。

## 优化什么

- 只执行当前宿主阶段
- 方法
- 执行边界

这些标题来自该包正文的章节，不是另一套执行规则。真正执行以包内 `SKILL.md` 为准。

## 输入

使用当前工作台已经提供的描述、选定素材和冻结参数。布局包还会读取自己的 `references/layout.json`。没有被该包声明的素材不是必需项。

## 输出

- 按剧情行动规划有序片段，而不是按固定秒数切段。
- 为单个片段写可独立提交的视频完整稿。

## 可预期效果

设计用途来自该包正文。本仓库没有为这个方法附上模型实测前后对照。

## 安装与启用

在比格熊中使用目录或 ZIP 导入 `examples/teaching/clip-method-selection`，预览后确认替换。单文件导入会丢掉 references 等附件，带布局的包不要只用单文件。
