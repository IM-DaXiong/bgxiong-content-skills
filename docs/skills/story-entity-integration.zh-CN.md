# 故事名单整合

状态：`teaching`。版本：`1.0.2`。工作流：`clips-v1`。包目录：`examples/teaching/story-entity-integration`。

## 用途

对照本次候选与当前故事名单，提出明确的角色或道具身份整合决定。同名不默认同人，引用只来自宿主给定闭集；适用于独立名单整合或显式审核已有对象。

## 适用场景

正在使用比格熊创作工作台、并选择了上述用途的作者。 声明用途：story-entity-integration。

- 把分散的角色、场景和道具整理进同一套故事实体。
