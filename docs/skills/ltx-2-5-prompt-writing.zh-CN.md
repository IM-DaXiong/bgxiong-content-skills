# LTX-2.5 视频提示词

状态：`source-approved`。版本：`1.4.0`。工作流：`clips-v1`。包目录：`skills/ltx-2-5-prompt-writing`。

## 用途

为 LTX 的文生视频、图生视频和首尾帧视频适配连贯段落，按时间组织动作、镜头、光线和声音，逐字保留原语言对白、歌词与用户画面文字，并按应用合同交付正负提示词。

## 适用场景

正在使用比格熊创作工作台、并选择了上述用途的作者。 声明用途：optimize-segment、clip-video-draft、video-prompt-projection。

- 工作流配置

这些标题来自该包正文的章节，不是另一套执行规则。真正执行以包内 `SKILL.md` 为准。

## 输入

使用当前工作台已经提供的描述、选定素材和冻结参数。布局包还会读取自己的 `references/layout.json`。没有被该包声明的素材不是必需项。

## 输出

- 检查片段连续性或表演问题，并给出仍可执行的修订建议。
- 为单个片段写可独立提交的视频完整稿。
- 把片段意图写成目标视频模型可阅读的提示词投影，不提交生成任务。
