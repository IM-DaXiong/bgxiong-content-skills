# 可灵视频提示词

状态：`source-approved`。版本：`1.1.1`。工作流：`clips-v1`。包目录：`skills/kling-prompt-writing`。

## 用途

依据冻结的 Kling Classic 或 Omni 目标，将片段视频稿表达为当前模式所需内容，保留真实引用与原话；经典版和 Omni 的资源与能力不混用。

## 适用场景

正在使用比格熊创作工作台、并选择了上述用途的作者。 声明用途：video-prompt-projection。

## 优化什么

- 片段与素材边界
- 本次输入与格式适配
- 目标资源
- 评审与交付

这些标题来自该包正文的章节，不是另一套执行规则。真正执行以包内 `SKILL.md` 为准。

## 输入

使用当前工作台已经提供的描述、选定素材和冻结参数。布局包还会读取自己的 `references/layout.json`。没有被该包声明的素材不是必需项。

## 输出

- 把片段意图写成目标视频模型可阅读的提示词投影，不提交生成任务。
