# Qwen Image 2.1 图像提示词

状态：`source-approved`。版本：`1.1.0`。工作流：`clips-v1`。包目录：`skills/qwen-image-2-1-prompt-writing`。

## 用途

为 Qwen Image 2.1 优化文生图与参考图编辑提示词。文生图整理为英文画面描述，图片编辑明确修改与保留内容，多图编号严格沿用输入顺序；画面文字保留用户指定语言。用于生图工作台点击优化提示词后审阅结果，不负责提交生图或改变画幅。

## 适用场景

正在使用比格熊创作工作台、并选择了上述用途的作者。 声明用途：optimize-image-prompt、clip-environment-prompt。

## 优化什么

- 片段与素材边界
- 输入与输出边界
- 文生图：描述已经完成的画面
- 图片编辑：明确改什么、保留什么
- 提交前检查
- 方法来源与有意适配
- 评审与交付

这些标题来自该包正文的章节，不是另一套执行规则。真正执行以包内 `SKILL.md` 为准。

## 输入

使用当前工作台已经提供的描述、选定素材和冻结参数。布局包还会读取自己的 `references/layout.json`。没有被该包声明的素材不是必需项。

## 输出

- 在已有图片提示词上标出可改进处并给出修订稿，保留原稿。
- 为片段中的环境候选写普通图片提示词。
