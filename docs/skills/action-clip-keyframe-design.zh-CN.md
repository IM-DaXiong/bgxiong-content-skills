# 武戏片段静帧设计

状态：`source-approved`。版本：`1.0.0`。工作流：`clips-v1`。包目录：`skills/action-clip-keyframe-design`。

## 用途

为武戏片段选择可读的单帧瞬间，为已选镜帧写图片提示词或分析姿态。适合交手、闪避、腾挪及动作后的反应；混合场景按当前镜头取用。

## 适用场景

正在使用比格熊创作工作台、并选择了上述用途的作者。 声明用途：clip-frame-plan、clip-frame-prompt。

## 优化什么

- 从片段稿取一拍
- 让动作在静图里读得出来
- 按这一拍的叙事选择机位和焦段
- 沿用已绑定的参考

这些标题来自该包正文的章节，不是另一套执行规则。真正执行以包内 `SKILL.md` 为准。

## 输入

使用当前工作台已经提供的描述、选定素材和冻结参数。布局包还会读取自己的 `references/layout.json`。没有被该包声明的素材不是必需项。

## 输出

- 为片段规划画面帧，不把规划本身当成已生成视频。
- 为已规划的画面帧写提示词。
