# 剧集创作

状态：`teaching`。版本：`2.0.1`。工作流：`clips-v1`。包目录：`examples/teaching/chapters-only`。

## 用途

根据当前故事原文创作剧集正文，按人物目标与事件因果组织各集起承转合。用户要把故事写成剧集，或修改已有剧集正文时使用；不生成场次、分镜或名单。

## 适用场景

正在使用比格熊创作工作台、并选择了上述用途的作者。 声明用途：story-chapters。

## 优化什么

- 方法
- 输入和返回边界
- 创作与执行合同

这些标题来自该包正文的章节，不是另一套执行规则。真正执行以包内 `SKILL.md` 为准。

## 输入

使用当前工作台已经提供的描述、选定素材和冻结参数。布局包还会读取自己的 `references/layout.json`。没有被该包声明的素材不是必需项。

## 输出

- 把故事材料整理成剧集章节结构。

## 可预期效果

设计用途来自该包正文。本仓库没有为这个方法附上模型实测前后对照。

## 安装与启用

在比格熊中使用目录或 ZIP 导入 `examples/teaching/chapters-only`，预览后确认替换。单文件导入会丢掉 references 等附件，带布局的包不要只用单文件。
