# H3 视频提示词

状态：`source-approved`。版本：`1.2.4`。工作流：`clips-v1`。包目录：`skills/h3-prompt-writing`。

## 用途

把应用提供的视频母版整理成项目内 h3@1 兼容提示词。适用于 T2VA、I2VA、FL2VA、L2VA 和 Ref2VA；保留母版事实、台词、时间与参考素材绑定，不负责新增剧情或猜测模型能力。

## 适用场景

正在使用比格熊创作工作台、并选择了上述用途的作者。 声明用途：video-prompt-projection。

## 优化什么

- 交付给用户的提示词
- 片段与素材边界
- 手选通用输出与专用编译职责
- 什么时候用
- 官方结构对照
- 不可改变的内容
- 工作方式
- 多人对白

这些标题来自该包正文的章节，不是另一套执行规则。真正执行以包内 `SKILL.md` 为准。

## 输入

使用当前工作台已经提供的描述、选定素材和冻结参数。布局包还会读取自己的 `references/layout.json`。没有被该包声明的素材不是必需项。

## 输出

- 把片段意图写成目标视频模型可阅读的提示词投影，不提交生成任务。

## 可预期效果
