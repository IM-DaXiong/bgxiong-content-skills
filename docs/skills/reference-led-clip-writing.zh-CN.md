# 按参考素材写剧本与分镜

状态：`source-approved`。版本：`1.0.1`。工作流：`clips-v1`。包目录：`skills/reference-led-clip-writing`。

## 用途

优化剧集剧本或撰写视频片段稿时，按用户原文和指定素材绑定主体、环境与音色，精简重复的外观描写和分镜说明。

## 适用场景

正在使用比格熊创作工作台、并选择了上述用途的作者。 声明用途：story-chapters、clip-video-draft。

## 优化什么

- 决定哪些内容要写
- 一次交代每份素材管什么
- 镜头写发生的变化

这些标题来自该包正文的章节，不是另一套执行规则。真正执行以包内 `SKILL.md` 为准。

## 输入

使用当前工作台已经提供的描述、选定素材和冻结参数。布局包还会读取自己的 `references/layout.json`。没有被该包声明的素材不是必需项。

## 输出

- 把故事材料整理成剧集章节结构。
- 为单个片段写可独立提交的视频完整稿。

## 可预期效果

设计用途来自该包正文。本仓库没有为这个方法附上模型实测前后对照。

## 安装与启用

在比格熊中使用目录或 ZIP 导入 `skills/reference-led-clip-writing`，预览后确认替换。单文件导入会丢掉 references 等附件，带布局的包不要只用单文件。
