# 动作打斗提示词

状态：`source-approved`。版本：`1.1.0`。工作流：`clips-v1`。包目录：`skills/action-fight-prompt`。

## 用途

为片段初稿或当前视频稿整理动作打斗表达，保持人物、空间、因果、声音与逐字原话；适用于现代格斗、持械和多人对抗，镜头与时长不套固定模板。

## 适用场景

正在使用比格熊创作工作台、并选择了上述用途的作者。 声明用途：optimize-segment、clip-video-draft。

## 优化什么

- 片段与素材边界
- 动作表达
- 阶段输出
- 评审与交付

这些标题来自该包正文的章节，不是另一套执行规则。真正执行以包内 `SKILL.md` 为准。

## 输入

使用当前工作台已经提供的描述、选定素材和冻结参数。布局包还会读取自己的 `references/layout.json`。没有被该包声明的素材不是必需项。

## 输出

- 检查片段连续性或表演问题，并给出仍可执行的修订建议。
- 为单个片段写可独立提交的视频完整稿。

## 可预期效果

设计用途来自该包正文。本仓库没有为这个方法附上模型实测前后对照。
