# BGX 动态包装设计

状态：`teaching`。版本：`0.2.0`。工作流：`clips-v1`。包目录：`examples/teaching/motion-design`。

## 用途

动态包装设计方法。根据当前片段的字幕/口播与已安装动态模板的 props schema，给出每张动态卡片用哪个模板、何时出现、填什么内容；只产出符合 design.schema 的 JSON 方案，不渲染、不安装、不改文件。

## 适用场景

正在使用比格熊创作工作台、并选择了上述用途的作者。 声明用途：postproduction-decoration。

- 你要交付什么

这些标题来自该包正文的章节，不是另一套执行规则。真正执行以包内 `SKILL.md` 为准。

## 输入

使用当前工作台已经提供的描述、选定素材和冻结参数。布局包还会读取自己的 `references/layout.json`。没有被该包声明的素材不是必需项。

## 输出

- 为已有画面补充后期装饰或动效方法，不替换成片成片文件。

## 可预期效果

设计用途来自该包正文。本仓库没有为这个方法附上模型实测前后对照。

在比格熊中使用目录或 ZIP 导入 `examples/teaching/motion-design`，预览后确认替换。单文件导入会丢掉 references 等附件，带布局的包不要只用单文件。
